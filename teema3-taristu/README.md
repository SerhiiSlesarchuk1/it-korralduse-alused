# Teema 3: IT-Infrastruktuur ja Taristu

## Põhimõisted
1. **Taristu (Infrastructure)** – Riistvara, tarkvara, võrkude ja rajatiste kogum, mis toetab IT-teenuste toimimist.
2. **Pilvetehnoloogia (Cloud Computing)** – Arvutiressursside (serverid, andmehoidlad) pakkumine interneti kaudu.
3. **Virtualiseerimine** – Tehnoloogia, mis võimaldab ühe füüsilise serveri jagada mitmeks virtuaalseks masinaks.
4. **Andmekeskus (Data Center)** – Füüsiline hoone või ruum, kus hoitakse servereid ja andmemassiive.
5. **Võrgutopoogia** – Arvutivõrgu sõlmede ja ühenduste füüsiline või loogiline paigutus.

## Mida õppisin
```
Sain teada, kuidas jaguneb kaasaegne IT-taristu füüsiliseks ja pilvepõhiseks lahenduseks. Mõistsin virtualiseerimise eeliseid kulude kokkuhoiu ja ressursside kiirema jagamise seisukohalt ning seda, kui kriitiline on tagada taristu turvalisus ja andmete varundus.
```

## Näide
```
Kooli arvutiklassi arvutid, kohalik serveriruum, kaablid ja WiFi-võrk moodustavad kokku kooli kohaliku IT-taristu.
```
