# Teema 2: Äriprotsessid ja nende juhtimine

## Põhimõisted
1. **Protsess (Process)** – Struktureeritud tegevuste jada, mis muudab sisendid väljunditeks ja loob väärtust.
2. **BPMN (Business Process Model and Notation)** – Standardiseeritud graafiline keel äriprotsesside joonistamiseks.
3. **Sisend (Input)** – Ressursid või andmed, mida protsessi alustamiseks vaja läheb.
4. **Väljund (Output)** – Protsessi lõpptulemus (toode, teenus või otsus).
5. **KPI (Key Performance Indicator)** – Mõõdik, mis näitab, kui efektiivselt protsess oma eesmärke täidab.

## Mida õppisin
```
Selle teema raames õppisin, et iga toimiv ettevõte põhineb hästi kirjeldatud protsessidel. Sain teada, kuidas protsesse kaardistada ning miks on oluline eemaldada pudelikaelad, mis aeglustavad töövoogu ja raiskavad ressursse.
```

## Näide
```
Uue õpilase vastu võtmise protsess koolis: avalduse esitamine (sisend) -> andmete kontroll -> otsuse kinnitamine -> õpilase nimekirja lisamine (väljund).
```
