# Teema 1: ITIL raamistik

## Põhimõisted
1. **ITIL (IT Infrastructure Library)** – Parimate praktikate kogu IT-teenuste haldamiseks (ITSM).
2. **Teenus (Service)** – Väärtuse loomise viis kliendile, ilma et klient peaks kandma spetsiifilisi riske ja kulusid.
3. **SLA (Service Level Agreement)** – Teenustaseme leping kliendi ja IT-pakkuja vahel, mis määrab teenuse kvaliteedi.
4. **Intsident (Incident)** – Planeerimata katkemine IT-teenuses või selle kvaliteedi langus.
5. **Probleem (Problem)** – Ühe või mitme intsidendi teadaolev põhjus, mida on vaja uurida.

## Mida õppisin
```
Õppisin tundma ITIL raamistiku põhistruktuuri ja elutsüklit. Sain aru, kui oluline on kliendi ja IT-osakonna vaheline selge kommunikatsioon ning teenuste disainimine vastavalt ärivajadustele. Intsidentide ja probleemide eristamine aitab IT-tugsüsteemi paremini organiseerida.
```
## Näide
Koolis e-päeviku (nt Tahvel) maha kukkumine on **intsident**. Kui see kordub igal esmaspäeval samal ajal, on see juba **probleem**, mille juurpõhjust tuleb uurida.

| Teenuse tüüp | Kirjeldus | Näide |
| :--- | :--- | :--- |

| Tugiteenus | Vajalik äriteenuse toimimiseks | Andmebaasid, serveri tugi |
