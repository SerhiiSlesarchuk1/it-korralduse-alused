# Teema 4: Lean mõtteviis IT-s

## Põhimõisted
1. **Lean** – Juhtimismetoodika, mille eesmärk on maksimeerida väärtust kliendile ja minimeerida raiskamist.
2. **Raiskamine (Muda)** – Iiga tegevus protsessis, mis kulutab ressurssi, kuid ei loo kliendile väärtust.
3. **Pidev parendamine (Kaizen)** – Lean-filosoofia osa, kus protsesse parendatakse samm-sammult ja pidevalt.
4. **Väärtusahel (Value Stream)** – Kõik tegevused, mis on vajalikud toote või teenuse toomiseks kliendini.
5. **Kanban** – Visuaalne süsteem töövoo juhtimiseks ja poolelioleva töö (WIP) piiramiseks.

## Mida õppisin
```
Õppisin märkama "raiskamisi" igapäevases töös ja tarkvaraarenduses (nt ülearune dokumentatsioon või ootamine). Lean õpetab mõtlema efektiivselt ja optimeerima tegevusi nii, et fookus oleks alati lõppkliendi rahulolul.
```

## Näide
```
Tarkvaraarenduses on raiskamiseks see, kui programmeerija kirjutab valmis funktsiooni, mida klient tegelikult kunagi ei palunud ega kasuta.
```

## Raiskamise tüübid IT-s
| Raiskamise liik | Selgitus IT kontekstis | Näide |
| :--- | :--- | :--- |
| Ootamine | Arendaja ootab serveri seadistamist või spetsifikatsiooni | Ootamine, kuni klienditugi vastab piletile |
| Ületootmine | Koodi kirjutamine varuks ilma reaalse vajaduseta | Liigsete funktsioonide arendamine |
| Defektid | Vigane kood, mis nõuab ümbertegemist ja testimist | Tarkvaravead (bugid) toodangukeskkonnas |
